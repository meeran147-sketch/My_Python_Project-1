# My_Python_Project-1
## Project Objective
The objective of this project is to analyze coffee sales data using Python and create meaningful visualizations. The project uses **Pandas, Matplotlib, and Seaborn** to explore sales, product categories, quantities, and unit prices.The visualizations provide a clear understanding of **sales performance, product trends, quantity distribution, and pricing**, helping to transform raw data into useful and easy-to-understand insights.This project demonstrates practical skills in **data analysis, data visualization, Python programming, and exploratory data analysis (EDA)**.
## Dataset used
- <a href="https://github.com/meeran147-sketch/Online-Sales-Performance-Dashboard/blob/main/Dashboard%202_Dataset.xlsx">Dataset</a>

## Question
- Which product category generates the highest total sales?
- Which product has the highest quantity sold?
- How does quantity vary across different products?
- Which product categories have the highest average quantity?
- How are total sales distributed among product categories?
- Which products have the highest unit prices?
- What patterns and trends can be identified from the coffee sales data?
- How can data visualization help in understanding coffee sales performance?

## Process

1. **Data Collection**  
   Import the coffee sales data from the `Coffee.xlsx` Excel file.

2. **Data Loading**  
   Use **Pandas** to read and load the Excel data into a DataFrame.

3. **Data Exploration**  
   Display and examine the dataset to understand the available columns, products, categories, sales, quantities, and prices.

4. **Data Grouping**  
   Group the data by **Product Category** and **Product Name** to calculate total sales, quantity, average quantity, and unit prices.

5. **Data Visualization**  
   Create different visualizations using **Matplotlib** and **Seaborn**, including:
   - Line charts
   - Histograms
   - Scatter plots
   - Box plots
   - Bar charts

6. **Analysis**  
   Compare products and categories to identify sales patterns, quantity differences, and pricing trends.

7. **Visualization & Insights**  
   Present the results through multiple charts and use them to understand the overall performance of the coffee products.

8. **Final Output**  
   Display all visualizations together in a clear and organized `2 × 3` subplot layout.
